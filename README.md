# Todo Application

A simple task management application built with React and TypeScript.

## Project Structure

```
src/
├── App.tsx
├── components/
│   ├── TodoForm.tsx
│   ├── TodoList.tsx
│   └── FilterBar.tsx
├── utils/
│   ├── storage.ts
│   └── helpers.ts
├── main.tsx
└── index.css
```

## Technology Stack

- React 18 with TypeScript
- Vite
- CSS

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
